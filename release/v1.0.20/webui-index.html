卸载内核模块

「卸载」= 把模块从内存里移除（rmmod），不会删除任何文件。
.ko 文件仍然在模块目录里，随时可以再点「加载」装回去。

· 未加载的模块显示「未加载」，按钮不可点（点了也只会报 not loaded，没有副作用）；
· 如果 Docker 容器或 Droidspaces 正占用模块，卸载会失败并显示 Device or resource busy，这时只能重启手机；
· 卸载后立刻失去对应能力（例如卸掉 misc → 「允许沙箱」失效），但不会关机。
